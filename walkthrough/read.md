### Read a file

```
  ▶  def process_order(order, customer):      ← beacon (enter here)
  │      log.info("processing")               ← tendon (dimmed, skip)
  ┃      if customer.tier == "gold":          ← muscle (the decision)
  ┃          discount = total * 0.15          ← muscle
  │      return total - discount              ← tendon
```

Experts don't read every line — they enter at the **beacon**, dwell on the
**muscle**, and skip the **tendon**. doloop paints that for you on a file
you've never opened. Hover any line to learn what it is and why.
